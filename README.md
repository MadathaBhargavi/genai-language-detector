A production-grade, full-stack **GenAI Language Detector** web application that analyzes written text to estimate whether it was written by a human or generated by an AI model (e.g., ChatGPT, Claude, Gemini).

Built with **FastAPI**, **Scikit-Learn**, and **Vanilla Modern CSS/JS**, this application calculates genuine stylometric, syntactic, and probabilistic metrics without relying on mock data, hardcoded percentages, or arbitrary numbers.

---

## 🚀 Key Features

- **Genuine Stylometric NLP & Machine Learning**:
  - Uses trained and calibrated probabilistic classification ($P(\text{AI} \mid X)$).
  - Evaluates sentence burstiness, n-gram entropy, lexical diversity, perplexity proxies, and discourse marker density.
- **Transparent Output**:
  - **AI Probability** & **Human Probability** (dual animated gauge).
  - **Confidence Level**: High, Medium, or Low.
  - **Categorized Results**:
    - `Likely AI-Generated` ($\ge 65\%$)
    - `Likely Human-Written` ($\le 35\%$)
    - `Mixed / AI-Assisted` ($35\% - 65\%$)
    - `Uncertain` (short or ambiguous text)
- **Deep Writing Analysis**:
  - Word count & sentence count
  - Average sentence length
  - Vocabulary diversity (Type-Token Ratio & richness)
  - Repetition rates (2-gram / 3-gram recurrence)
  - Sentence variation (Burstiness standard deviation & CV)
  - Writing consistency & Flesch readability grade
- **Sentence-by-Sentence Heat Map**:
  - Highlights each individual sentence with color-coded authorship likelihood tags (`likely_human`, `mixed`, `likely_ai`).
  - Clickable sentence inspection showing sentence word count and estimated AI likelihood.
- **Document Upload**:
  - Direct upload support for **`.txt`**, **`.pdf`** (via `pypdf`), and **`.docx`** (via `python-docx`).
- **Interactive UI & Themes**:
  - Sleek modern AI SaaS aesthetic (dark & light mode support).
  - Quick-load benchmark samples (Human Story, AI Essay, Mixed Writing).
  - One-click **Copy Summary Report** and **Export JSON**.
- **Probabilistic Disclaimer**:
  - Prominently displays: *"AI detection is probabilistic. This result is an estimate based on linguistic patterns and should not be considered definitive proof of authorship."*

## 🧠 How the Detector Works

Unlike simplistic keyword checkers or black-box wrappers, this engine analyzes multi-dimensional linguistic vectors:

1. **Burstiness & Syntactic Variation**:
   - Humans naturally vary sentence length (mixing punchy short clauses with long, descriptive sentences).
   - Large Language Models (LLMs) maintain a distinctly uniform rhythm, resulting in low standard deviation across sentence lengths.
2. **Perplexity & Statistical Surprise**:
   - LLMs generate tokens that maximize conditional probability, resulting in lower character and word n-gram entropy.
   - Human writing includes spontaneous word choices, idioms, typos, and higher idiosyncratic variety.
3. **Discourse Markers & Transition Density**:
   - Models heavily over-index on formulaic academic transitions (`"furthermore"`, `"it is important to note"`, `"delve"`, `"tapestry"`, `"crucial"`, `"pivotal"`, `"a testament to"`).
4. **Contractions & Informality**:
   - Natural human writing regularly employs contractions (`"don't"`, `"can't"`, `"it's"`), whereas LLMs default toward formal expansions.
5. **Calibrated Logistic Classifier**:
   - Standardized feature vectors are passed through a regularized, cross-validated logistic classifier that outputs well-calibrated posterior probabilities.

## ⚙️ Quick Start & Setup

### 1. Prerequisites
- Python 3.10+ installed
- Node.js (optional, for `npm` shortcut scripts)

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. (Optional) Re-train or Update the Model
The pre-trained model is already included in `backend/detector/model_artifact.joblib`. To re-train:
```bash
python -m backend.detector.trainer
```

### 4. Run the Application
Start the FastAPI server (serves both API and frontend):
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
Or with npm:
```bash
npm run dev
```

Open your browser and navigate to:
```
http://127.0.0.1:8000
```

Interactive Swagger API Documentation is available at:
```
http://127.0.0.1:8000/docs
```

`GET /api/health`
```json
{
  "status": "healthy",
  "service": "GenAI Language Detector",
  "version": "1.0.0",
```

`POST /api/analyze`

**Request:**
```json

  "text": "Artificial intelligence has fundamentally transformed the modern technological landscape..."
}
```

**Response:**
```json
{
  "valid": true,
  "result": "Likely AI-Generated",
  "ai_probability": 0.969,
  "human_probability": 0.031,
  "confidence": "High",
  "word_count": 87,
  "sentence_count": 5,
  "average_sentence_length": 17.4,
  "writing_analysis": {
    "words": 87,
    "sentences": 5,
    "average_sentence_length": 17.4,
    "vocabulary_diversity": "Medium",
    "vocabulary_diversity_score": 68.2,
    "repetition": "Low",
    "repetition_score": 3.4,
    "sentence_variation": "Low",
    "sentence_variation_std": 2.1,
    "writing_consistency": "High",
    "readability_score": 32.5,
    "readability_level": "Complex / Academic"
  },
  "sentence_breakdown": [
    {
      "text": "Artificial intelligence has fundamentally transformed...",
      "label": "likely_ai",
      "ai_prob": 0.94,
      "word_count": 13
    }

  "signals": [
    "Low sentence-length variation (uniform sentence cadence characteristic of LLMs)",
    "Elevated frequency of formulaic transition markers (2.3 per 100 words)"
  ],
  "disclaimer": "AI detection is probabilistic. This result is an estimate based on linguistic patterns and should not be considered definitive proof of authorship."

```

### 3. Upload Document
`POST /api/upload`
- Multipart form upload with field `file` (`.txt`, `.pdf`, `.docx`).
- Returns extracted text and word counts.

### 4. Sample Texts
`GET /api/samples`
- Returns verified human, AI, and mixed sample texts for testing.

## ⚠️ Known Limitations & Probabilistic Disclaimer

- **Short Texts (< 30 words)**: Stylometric statistics (burstiness, variance, entropy) require sufficient sample size. Texts under 25 words return `Uncertain` with a recommendation to supply more text.
- **Heavy Editing / Paraphrasing**: Texts that combine AI generation with extensive human editing will score as `Mixed / AI-Assisted`.
- **Probabilistic Nature**: No AI detector is 100% accurate. Scores represent statistical estimates of linguistic patterns and should never be used as singular punitive evidence.
